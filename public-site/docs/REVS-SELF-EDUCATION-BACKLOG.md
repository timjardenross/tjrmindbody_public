# REVS Self-Education Backlog

This backlog defines the 12 capacity-system self-education modules plus the REC-001 gateway module that sit beneath the REVS core concepts and stage journey.
It uses the shared module template so every system can be taught in the same low-load, repeatable structure.

## Purpose

- Turn each capacity system into a standalone learning module
- Keep the pedagogy consistent across all 12 systems
- Make the modules usable as text, HTML, PDF, or interactive content
- Keep the module layer separate from atomic concepts so the content architecture stays modular

## Shared Module Schema

Each module should include these fields:

- `module_id`
- `concept_id`
- `title`
- `stage`
- `system`
- `learning_objective`
- `why_it_matters`
- `time_estimate`
- `prerequisites`
- `audience_framings`
- `core_text`
- `orient_section`
- `understand_section`
- `reflect_section`
- `act_section`
- `integrate_section`
- `anchor_phrase`
- `next_modules`
- `formats`
- `depths`
- `evidence_citations`
- `accessibility_notes`
- `completion_criteria`

## Shared Module Rules

- Every module uses the same five-part progression: `Orient`, `Understand`, `Reflect`, `Act`, `Integrate`
- Every module should stand alone, but also connect to the wider stage journey
- Every module should include a clear next step
- Every module should be editable into poster, article, worksheet, presentation, video, podcast, and social versions
- Every module should keep cognitive load low and language plain

## First Four Module Drafts

### REC-001

- **Module ID:** REC-001
- **Title:** The 12 Interconnected Capacity Systems
- **Stage:** Recognise
- **System:** 12 Capacity Systems Overview
- **Learning Objective:** Help users understand the 12 systems as one interconnected map and see why the assessment is about capacity, not diagnosis.
- **Why It Matters:** Users often think they are one problem; this module shows them how the systems interact and why patterns make more sense when viewed together.
- **Time Estimate:** 20-30 minutes
- **Prerequisites:** CORE-001, PRINCIPLES
- **Core Message:** You are not broken. You are a complex system, and your capacity changes when the 12 systems interact differently.
- **Orient:** The user stops blaming themselves and sees the 12 systems as a clearer explanation for unpredictable symptoms.
- **Understand:** Explain the 12 systems, the web of interdependence, and the key pattern examples like pain, sleep, sensory load, and nervous system state.
- **Reflect:** Ask where the user notices the biggest system interactions, what keeps repeating, and which system seems to trigger the others.
- **Act:** Invite the user to map 3-4 systems at a time and notice one connection they can test this week.
- **Integrate:** Ask the user to write one sentence that captures the new framing: "I am not one problem; I am a system with patterns."
- **Anchor Phrase:** "Everything affects everything."
- **Next Modules:** REC-002, REC-003

### REC-002

- **Module ID:** REC-002
- **Title:** Pain & Physical Load
- **Stage:** Recognise
- **System:** Pain & Physical Load
- **Learning Objective:** Help users notice pain and physical load as capacity signals rather than personal failure.
- **Why It Matters:** Pain changes what is possible, and pain load often interacts with sleep, sensory processing, and nervous system state.
- **Time Estimate:** 20-30 minutes
- **Prerequisites:** REC-001
- **Core Message:** Pain is real information about load, not proof that you are doing life wrong.
- **Orient:** Show a situation where pain changes across days even when the user thinks nothing has changed.
- **Understand:** Explain how pain, load, and nervous system state interact and why same pain can feel different in different conditions.
- **Reflect:** Ask where the user notices pain affecting decisions, energy, or confidence.
- **Act:** Invite the user to identify one physical load they can reduce or one recovery action they can protect.
- **Integrate:** Ask the user to note one change in how they interpret pain: "Pain is data, not a verdict."
- **Anchor Phrase:** "Pain is data."
- **Next Modules:** REC-003, REC-004

### REC-003

- **Module ID:** REC-003
- **Title:** Nervous System State
- **Stage:** Recognise
- **System:** Nervous System State
- **Learning Objective:** Help users notice activation, regulation, and overload patterns in their own body and behaviour.
- **Why It Matters:** Nervous system state shapes pain, energy, attention, sensory tolerance, and recovery.
- **Time Estimate:** 20-30 minutes
- **Prerequisites:** REC-001
- **Core Message:** Your nervous system is not a character flaw; it is a system that responds to load, threat, and recovery.
- **Orient:** Introduce a simple example of activation building over a day.
- **Understand:** Explain what activation, regulation, and overload look like in practice, and how they influence other systems.
- **Reflect:** Ask what the user notices first when their system is activated and what helps bring it down.
- **Act:** Invite the user to choose one small regulation action they can repeat when activation rises.
- **Integrate:** Ask the user to write one phrase that reminds them to slow down before overload.
- **Anchor Phrase:** "Notice it early."
- **Next Modules:** REC-004, REC-005

### REC-004

- **Module ID:** REC-004
- **Title:** Recovery Cycles
- **Stage:** Recognise
- **System:** Recovery Cycles
- **Learning Objective:** Help users see sleep, rest, and downtime as active capacity builders, not optional extras.
- **Why It Matters:** Recovery cycles shape how much strain the system can handle and how quickly it returns to baseline.
- **Time Estimate:** 20-30 minutes
- **Prerequisites:** REC-001, REC-003
- **Core Message:** Recovery is not wasted time; it is the mechanism that allows the system to keep functioning.
- **Orient:** Show a simple before-and-after story where poor rest changes the whole day.
- **Understand:** Explain how sleep debt and recovery debt affect capacity across the other systems.
- **Reflect:** Ask what most often interrupts recovery and what support would make it more possible.
- **Act:** Invite the user to protect one recovery block this week.
- **Integrate:** Ask the user to name one thing they will treat as non-negotiable recovery.
- **Anchor Phrase:** "Recovery is capacity work."
- **Next Modules:** REC-005, REC-006

### REC-005

- **Module ID:** REC-005
- **Title:** Sensory Processing & Load
- **Stage:** Recognise
- **System:** Sensory Processing & Load
- **Learning Objective:** Help users notice how sensory input accumulates and why overload is often predictable once the pattern is visible.
- **Why It Matters:** Sensory load affects nervous system state, energy, focus, pain, and the ability to stay present.
- **Time Estimate:** 20-30 minutes
- **Prerequisites:** REC-001, REC-003
- **Core Message:** Sensory overload is not overreaction; it is a real load issue that can be observed and reduced.
- **Orient:** Show a simple day where sound, light, interruptions, or touch make the system less able to cope.
- **Understand:** Explain sensory thresholds, cumulative load, and how overload can build even when each input feels “small.”
- **Reflect:** Ask which sensory inputs deplete the user fastest and where they first notice overload in the body or behaviour.
- **Act:** Invite the user to change one sensory condition this week and notice what shifts.
- **Integrate:** Ask the user to write one sentence about their sensory needs without apology.
- **Anchor Phrase:** "Small inputs add up."
- **Next Modules:** REC-006, REG-001

### REC-006

- **Module ID:** REC-006
- **Title:** Energy & Fatigue
- **Stage:** Recognise
- **System:** Energy & Fatigue
- **Learning Objective:** Make energy visible as a finite, variable resource and help users notice what restores or drains it.
- **Why It Matters:** Energy touches every system, and fatigue often explains why capacity drops even when motivation is high.
- **Time Estimate:** 20-30 minutes
- **Prerequisites:** REC-001, REC-004
- **Core Message:** Energy is not moral worth; it is a capacity resource that changes with load and recovery.
- **Orient:** Show a day where the user’s effort looks the same on the outside but their energy budget is very different.
- **Understand:** Explain how fatigue builds, why effort alone does not restore capacity, and how energy relates to the other systems.
- **Reflect:** Ask what reliably drains the user and what reliably restores them, even a little.
- **Act:** Invite the user to choose one energy-protecting action to repeat for a week.
- **Integrate:** Ask the user to name the sign that tells them they are spending from a depleted energy reserve.
- **Anchor Phrase:** "Energy is a budget."
- **Next Modules:** REG-001

### REG-001

- **Module ID:** REG-001
- **Title:** Emotional Regulation & Affect
- **Stage:** Regulate
- **System:** Emotional Regulation & Affect
- **Learning Objective:** Help users notice emotional activation and stabilise it with less pressure and less shame.
- **Why It Matters:** Emotional strain can amplify pain, reduce focus, strain relationships, and make recovery harder.
- **Time Estimate:** 20-30 minutes
- **Prerequisites:** REC-001, REC-003, REC-006
- **Core Message:** Emotions are not the enemy; they are signals that become easier to work with when the system has support.
- **Orient:** Show how emotional activation can build after a difficult conversation, interruption, or unexpected change.
- **Understand:** Explain affect, regulation, and overwhelm in plain language, and how they interact with nervous system state.
- **Reflect:** Ask what emotions are hardest for the user to regulate and what helps them settle.
- **Act:** Invite the user to choose one regulation strategy that is realistic when they are already activated.
- **Integrate:** Ask the user to write one non-judgmental statement they can use when emotions feel intense.
- **Anchor Phrase:** "Regulate, don't wrestle."
- **Next Modules:** REG-002, REB-001

### REG-002

- **Module ID:** REG-002
- **Title:** Relationships & Social Demand
- **Stage:** Regulate
- **System:** Relationships & Social Demand
- **Learning Objective:** Help users understand how social load, conflict, care, and boundary setting shape capacity.
- **Why It Matters:** Relationship demand can either stabilise the system or quietly deplete it all day long.
- **Time Estimate:** 20-30 minutes
- **Prerequisites:** REG-001, REC-006
- **Core Message:** Social life is part of capacity management, not separate from it.
- **Orient:** Show how a normal-looking social day can be more exhausting than a physically busy one.
- **Understand:** Explain emotional labour, boundaries, repair, and how social demand influences energy and regulation.
- **Reflect:** Ask which relationships support regulation and which ones leave the user depleted.
- **Act:** Invite the user to try one boundary or repair action that lowers social strain.
- **Integrate:** Ask the user to write one sentence that respects their social limits without over-explaining.
- **Anchor Phrase:** "Connection should not cost everything."
- **Next Modules:** REB-001, REB-002

### REB-001

- **Module ID:** REB-001
- **Title:** Work & Productivity
- **Stage:** Rebuild
- **System:** Work & Productivity
- **Learning Objective:** Help users redesign work so it fits real capacity instead of forcing heroic output.
- **Why It Matters:** Work demands often collide with energy, cognition, pain, and recovery, so the solution has to be sustainable.
- **Time Estimate:** 20-30 minutes
- **Prerequisites:** REG-001, REG-002
- **Core Message:** Sustainable work is not doing more; it is doing what can actually be repeated.
- **Orient:** Show how a user’s work day can look successful from the outside while quietly draining capacity.
- **Understand:** Explain output, pacing, cognitive load, and why sustainable work patterns outperform heroic bursts.
- **Reflect:** Ask what part of work drains the user most and what would make the day more repeatable.
- **Act:** Invite the user to redesign one part of their work rhythm for sustainability.
- **Integrate:** Ask the user to define what “enough” looks like in a way that protects capacity.
- **Anchor Phrase:** "Repeatable beats impressive."
- **Next Modules:** REB-002, RED-001

### REB-002

- **Module ID:** REB-002
- **Title:** Cognition & Executive Function
- **Stage:** Rebuild
- **System:** Cognition & Executive Function
- **Learning Objective:** Help users support planning, attention, task initiation, and working memory with lower cognitive load.
- **Why It Matters:** Executive function strain can make ordinary tasks feel much larger than they look on paper.
- **Time Estimate:** 20-30 minutes
- **Prerequisites:** REB-001, REC-003, REC-006
- **Core Message:** Executive function is a capacity system, not a measure of intelligence or effort.
- **Orient:** Show a familiar moment where starting, switching, or remembering is harder than expected.
- **Understand:** Explain how cognitive load, attention, and task initiation interact, and why simplification helps.
- **Reflect:** Ask where the user gets stuck most often and what support helps them get moving.
- **Act:** Invite the user to simplify one routine, decision, or task into smaller steps.
- **Integrate:** Ask the user to name one support they can reuse when cognition is overloaded.
- **Anchor Phrase:** "Simpler is stronger."
- **Next Modules:** RED-001, RED-002

### RED-001

- **Module ID:** RED-001
- **Title:** Environment & Physical Space
- **Stage:** Redesign
- **System:** Environment & Physical Space
- **Learning Objective:** Help users change surroundings so they support capacity instead of constantly draining it.
- **Why It Matters:** Environment shapes sensory load, focus, recovery, and pain, often more than people realise.
- **Time Estimate:** 20-30 minutes
- **Prerequisites:** REB-001, REB-002
- **Core Message:** The room, schedule, and environment are part of the intervention.
- **Orient:** Show how a physical space can quietly add friction all day.
- **Understand:** Explain environmental triggers, friction points, and the logic of changing the setting instead of the person.
- **Reflect:** Ask which environmental factor affects the user most and where they feel the biggest drag.
- **Act:** Invite the user to change one environmental condition this week.
- **Integrate:** Ask the user to write one note about how the right environment changes capacity.
- **Anchor Phrase:** "Change the room, change the load."
- **Next Modules:** RED-002, RED-003

### RED-002

- **Module ID:** RED-002
- **Title:** Masking & Authenticity
- **Stage:** Redesign
- **System:** Masking & Authenticity
- **Learning Objective:** Help users reduce the hidden cost of performance and increase authentic self-expression.
- **Why It Matters:** Masking can protect safety in the short term, but it also drains energy and can hide real needs.
- **Time Estimate:** 20-30 minutes
- **Prerequisites:** RED-001, REG-001
- **Core Message:** Authenticity is not indulgence; it is a capacity support when it is safe and possible.
- **Orient:** Show how masking can look like coping while quietly consuming energy.
- **Understand:** Explain masking load, identity strain, and how authenticity affects regulation and relationships.
- **Reflect:** Ask where the user masks most and what the cost of that masking is.
- **Act:** Invite the user to reduce one unnecessary mask in a safe context.
- **Integrate:** Ask the user to write one sentence that names what authenticity gives back to them.
- **Anchor Phrase:** "Less performing, more capacity."
- **Next Modules:** RED-003

### RED-003

- **Module ID:** RED-003
- **Title:** Purpose & Meaning
- **Stage:** Redesign
- **System:** Purpose & Meaning
- **Learning Objective:** Help users connect capacity to values, meaning, and sustainable direction.
- **Why It Matters:** Meaning helps people choose what matters, what can wait, and what is worth protecting.
- **Time Estimate:** 20-30 minutes
- **Prerequisites:** RED-001, RED-002
- **Core Message:** Capacity is easier to protect when it is connected to a purpose that feels real.
- **Orient:** Show how purpose can steady a person when the system is under strain.
- **Understand:** Explain how meaning, values, and direction help shape sustainable decisions and boundaries.
- **Reflect:** Ask what gives the user energy, direction, or a sense that their effort matters.
- **Act:** Invite the user to choose one values-aligned action that supports their current capacity.
- **Integrate:** Ask the user to write a commitment that links capacity with meaning.
- **Anchor Phrase:** "Meaning makes the effort worth it."
- **Next Modules:** Review the full set or return to REC-001 as needed
